
# Burp Suite Web Security Labs

**Author:** Shayan Gayen

**Role:** Aspiring SOC Analyst | Cybersecurity Learner

## About This Project

This repository documents my hands-on learning journey
with Burp Suite Community Edition and web application
security testing.

The purpose of this project is to understand HTTP traffic,
analyze web requests and responses, and practice
fundamental web security testing techniques.

## Lab Environment

- Operating System: Windows 11
- Security Tool: Burp Suite Community Edition
- Practice Platform: PortSwigger Web Security Academy
- Testing Type: Authorized Educational Labs

## Learning Objectives

- Understand HTTP requests and responses
- Learn Burp Suite Proxy
- Analyze HTTP headers and parameters
- Practice request analysis using Repeater
- Understand cookies and sessions
- Learn fundamental web security concepts
- Document findings professionally
