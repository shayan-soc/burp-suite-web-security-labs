 1. Objective

The objective of this lab is to understand how HTTP traffic works and how Burp Suite Proxy can be used to inspect HTTP requests and responses.

 2. Lab Environment

- Operating System: Windows 11
- Tool: Burp Suite Community Edition
- Browser: Burp Suite's built-in browser
- Practice Environment: Authorized PortSwigger Academy lab

 3. Concepts to Understand

- HTTP Request
- HTTP Response
- HTTP Methods (GET, POST)
- HTTP Headers
- Status Codes
- Cookies and Sessions
- Proxy Interception

 4. Methodology

1. Launch Burp Suite Community Edition.
2. Open Proxy and launch Burp's built-in browser.
3. Visit an authorized PortSwigger Academy practice lab.
4. Open Proxy → HTTP history.
5. Select an HTTP request.
6. Inspect the request method, URL, headers and parameters.
7. Inspect the corresponding server response.
8. Record observations without exposing sensitive information.
